## [0.1.0] - 2026-02-05

### Added

- Initial release of TimeTrack package
- Multi-backend support (Toggl, fixtures, mock)
- Automated lunch break insertion (`set-lunch` command)
- Multi-system timesheet reporting (`report` command)
- Remaining hours calculation (`remaining` command)
- Support for TimeReg, xLedger, and custom reporting systems
- Fixture recording for offline development
- Comprehensive test suite
- Type checking with `ty`
- Code quality tools (ruff)
